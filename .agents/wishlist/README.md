# Wishlist Directory (`.agents/wishlist/`)

This directory contains feature ideas, potential improvements, conceptual backlogs, and roadmap items for the project.

---

## File Naming Convention

Format: `YYYY-MM-DD-feature-name.md`  
Example: `2025-08-12-integration-test-suite.md`

---

## Wishlist Item Template

New wishlist items should follow this markdown template:

```markdown
---
title: "Short feature title"
status: "idea" # idea | under-consideration | planned | discarded
author: "human" # human | agent
created: "YYYY-MM-DD"
---

## Summary
High-level description of the feature or improvement.

## Motivation / Use Case
Why is this feature valuable? What user need or system capability does it address?

## Proposed Concept
Overview of the conceptual approach or state machine additions without locking into code details.

## Open Questions
- Question 1?
- Question 2?
```
