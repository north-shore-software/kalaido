## Summary
Change the create space / kalaidoscope setup flow so that users select a color instead of selecting an icon. For the relevant scope, render the K selector wordmark using that selected color.

## Motivation / Use Case
Simplify scope identity during space creation by using color branding instead of icon selection, and dynamically theme the scope's K wordmark in the selector.

## Proposed Concept
- In the create space flow, replace the icon picker step with a color selection picker.
- Render the scope's K selector wordmark tinted/filled with the chosen color for that scope.
