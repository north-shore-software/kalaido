## Summary
An easy button "fork" style function to create a projection based off an existing one, optionally including full fragment scope as well or not (refine or orthogonal).

## Motivation / Use Case
Quickly create a new projection derived from an existing projection without manually setting it up from scratch.

## Proposed Concept
Provide an easy button "fork" feature on projections that creates a new projection based off an existing projection, with options regarding fragment scope and projection relationship (refine or orthogonal).

## Open Questions
- Should full fragment scope be included when forking, or made optional?
- Is the forked projection framed as a refine or orthogonal projection?
