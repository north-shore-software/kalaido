## Summary
Allow users to convert or promote an existing conversation from the vanilla "Chat" view (the main chat entry in the left navigation) directly into a Projection and/or Reflection.

## Motivation / Use Case
Users often start exploring ideas or synthesizing thoughts in a standard chat session. When that conversation yields a useful lens or summary structure, users want to save or promote it directly into a recurring/persisted Projection or Reflection without re-typing their prompts or recreating the context manually.

## Proposed Concept
Provide an action (e.g., button, menu option, or transition) within a vanilla Chat session that allows creating a Projection or Reflection initialized with the current conversation's content and context.

## Open Questions
- Should this create a Projection, a Reflection, or give the user the choice between both?
