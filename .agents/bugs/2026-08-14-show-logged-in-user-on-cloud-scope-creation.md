## Description
When creating a new cloud scope, if the user is already logged in, the UI should explicitly show who (which account/email) they are currently logged in as.

## Steps to Reproduce
1. Log into an account.
2. Navigate to the page/form to create a new cloud scope.
3. Observe the displayed account/user information.

## Expected Behavior
The page should clearly display the identity (e.g., account name or email) of the logged-in user.

## Observed Behavior
The page does not indicate or display who the user is logged in as.

- Affected files: None explicitly named by user
