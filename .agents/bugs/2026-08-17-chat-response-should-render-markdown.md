## Description
Chat responses should render formatted markdown rather than plain text or raw markdown syntax.

## Steps to Reproduce
1. Receive or view a chat response containing markdown syntax.
2. Check how the response is rendered in the chat view.

## Expected Behavior
Chat responses render properly as formatted markdown (code blocks, lists, bolding, headings, etc.).

## Observed Behavior
Chat responses do not render as formatted markdown.

## Context / Relevant Code
- Affected UI/components: Chat view / message response component
- Notes: Reported during chat view testing.
