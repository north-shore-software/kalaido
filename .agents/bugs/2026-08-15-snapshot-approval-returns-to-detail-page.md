## Summary
Navigating from the homepage dashboard to review a snapshot and clicking "Approve" takes the user back to the snapshot detail page.

## Description
When navigating from the homepage dashboard to review a snapshot, hitting approve redirects back to the snapshot detail page, which is annoying. User suggests adding an "approve and review next" button so snapshots can be reviewed in sequence.

## Steps to Reproduce
1. Navigate from the homepage dashboard to review a snapshot.
2. Click "Approve".
3. Observe that it redirects back to the snapshot detail page.

## Expected Behavior
An efficient workflow after approving a snapshot (e.g., an "approve and review next" button to process pending snapshots sequentially).

## Observed Behavior
Hitting approve returns to the snapshot detail page.

## Context / Relevant Code
- Affected files: None explicitly named by user
- Notes: User reported: "if you go from homepage dashbaord to review snapshot, and then hit approve - it takes you back to the snapshot detail, which is annoying. maybe we need a "approve and review next" button, so you can go through them in sequence"
