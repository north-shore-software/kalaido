## Summary
Users cannot pick or specify a name when creating a new projection.

## Description
When creating a new projection, there is no option or capability to choose/enter a name for the projection.

## Steps to Reproduce
1. Initiate creation of a new projection.
2. Attempt to pick or set the name for the projection during creation.

## Expected Behavior
Ability to pick/specify a name when creating a new projection.

## Observed Behavior
Cannot pick or enter a name when creating a new projection.
