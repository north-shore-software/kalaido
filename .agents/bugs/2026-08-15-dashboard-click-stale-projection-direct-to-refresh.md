## Summary
On the homepage dashboard, when a projection needs regenerating, clicking on it takes the user to the projection detail page first instead of straight to refresh.

## Description
When a projection needs regenerating on the homepage dashboard, clicking it should navigate straight to refresh rather than the projection detail page. Landing on the detail page first feels odd and adds an unnecessary extra click.

## Steps to Reproduce
1. Navigate to the homepage dashboard.
2. Click on a projection marked as needing regeneration.
3. Observe that it opens the projection detail page instead of refreshing directly.

## Expected Behavior
Clicking a projection that needs regenerating should take the user straight to refresh.

## Observed Behavior
Clicking takes the user to the projection detail page first, requiring an extra click to refresh.
