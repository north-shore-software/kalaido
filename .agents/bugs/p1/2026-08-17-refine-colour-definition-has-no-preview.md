## Description
When refining a colour definition, there is no live preview available, so users have no way to verify whether the updated definition is good or accurate before applying it.

## Steps to Reproduce
1. Navigate to refine a colour definition.
2. Observe the interface while making adjustments.

## Expected Behavior
A preview should be available during colour definition refinement to show how the changes affect matched results.

## Observed Behavior
No preview is shown, making it impossible to evaluate if the refined definition works well.

## Context / Relevant Code
- Affected UI/components: Refine colour definition UI / panel
- Notes: Reported during colour definition workflow.
