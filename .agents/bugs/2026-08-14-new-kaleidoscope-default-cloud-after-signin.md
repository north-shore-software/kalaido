## Description
When arriving on the "New Kaleidoscope" page after clicking "Sign in" on the initial onboarding page, the default selected option should be "Cloud", not "Local".

## Steps to Reproduce
1. Start on the initial onboarding page.
2. Click "Sign in" and complete the sign-in path.
3. Arrive on the "New Kaleidoscope" page and observe which option is selected by default.

## Expected Behavior
"Cloud" should be the default selected option on the "New Kaleidoscope" page when arriving from the sign-in path.

## Observed Behavior
"Local" is currently the default selected option.
